# Stage 1: Java Fundamentals

Welcome to **Java Fundamentals**. This directory contains everything needed to master Core Java programming before entering Object-Oriented Programming (OOP).

## Package Naming Convention
All classes in this module follow the package naming convention:
`package com.JavaFundamentals.<subfolder>;`

## Folder Overview
1. [`Basics/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/JavaFundamentals/Basics/README.md) - JDK, JRE, JVM, javac, bytecode, JIT, main method, identifiers, keywords, comments.
2. [`VariablesAndDataTypes/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/JavaFundamentals/VariablesAndDataTypes/README.md) - Primitive data types, literals, widening/narrowing casting, final constants, variable scope.
3. [`Operators/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/JavaFundamentals/Operators/README.md) - Arithmetic, relational, logical, assignment, increment/decrement, bitwise, precedence.

5. [`Methods/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/JavaFundamentals/Methods/README.md) - Method parameters, return types, call-by-value, static vs instance methods, overloading.
6. [`Recursion/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/JavaFundamentals/Recursion/README.md) - Base cases, call stack frames, factorial, fibonacci, array/string recursion.

9. [`InputOutput/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/JavaFundamentals/InputOutput/README.md) - `System.out` formatting, `Scanner` input parsing, buffer pitfalls.
