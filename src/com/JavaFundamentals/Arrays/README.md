# Arrays in Java

## Characteristics
- **Fixed Size**: Array size cannot be changed after instantiation.
- **Homogeneous**: Holds elements of identical data type.
- **Index-Based**: Zero-indexed (`0` to `length - 1`).
- **Memory**: Stored in contiguous memory locations on the Heap.

## Common Utility Methods (`java.util.Arrays`)
- `Arrays.sort(arr)`: Sorts primitives/objects.
- `Arrays.binarySearch(arr, key)`: Finds key in sorted array in O(log N).
- `Arrays.copyOf(arr, newLength)`: Copies array to new size.
- `Arrays.equals(arr1, arr2)`: Deep equality check.
