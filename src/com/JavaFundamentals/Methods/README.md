# Java Methods

## Key Principles
1. **DRY (Don't Repeat Yourself)**: Methods promote modularity and code reuse.
2. **Call-By-Value**: Java always passes arguments by value. For primitives, a copy of the value is passed. For objects, a copy of the reference address is passed.
3. **Method Signature**: Consists of method name + parameter types list (return type is NOT part of signature).
