# Java Basics & Architecture

## Concepts Covered
- **What is Java**: High-level, object-oriented, class-based, write-once-run-anywhere (WORA) programming language.
- **JDK (Java Development Kit)**: Complete toolkit containing compiler (`javac`), tools, and JRE.
- **JRE (Java Runtime Environment)**: Runtime libraries and JVM required to execute Java bytecodes.
- **JVM (Java Virtual Machine)**: Abstract virtual engine that executes compiled Java bytecode (`.class` files).
- **javac**: Java Compiler converting `.java` source code into platform-independent `.class` bytecode.
- **JIT Compiler**: Just-In-Time compiler inside JVM that compiles bytecode into native machine code at runtime for performance optimization.
