# Control Flow Statements

## Summary
Control flow statements determine the order in which statements are executed in a program.

## Loop Comparison
- **`for` loop**: Best when the number of iterations is known in advance.
- **`while` loop**: Best when looping condition depends on dynamic runtime criteria.
- **`do-while` loop**: Guarantees at least one execution before condition evaluation.
- **Enhanced `for-each`**: Preferred for iterating arrays and Collection structures without explicit index management.
