# Stage 3: Advanced Java & Java for DSA

Welcome to **Advanced Java**. This stage covers post-core advanced topics, functional features, concurrency, memory architecture, and Java tools for competitive programming and DSA.

## Package Naming Convention
All classes in this module follow the package naming convention:
`package com.AdvancedJava.<subfolder>;`

2. [`ExceptionHandling/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/AdvancedJava/ExceptionHandling/README.md) - Throwable hierarchy, checked vs unchecked exceptions, try-catch-finally, multi-catch, custom exceptions, try-with-resources.

9. [`Multithreading/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/AdvancedJava/Multithreading/README.md) - Thread lifecycle, Runnable, Callable, Future, race conditions, synchronized, volatile, Atomic variables, ReentrantLock, ReadWriteLock, ExecutorService, thread pools, ScheduledExecutorService, RejectedExecutionException, CompletableFuture, Concurrent collections.
