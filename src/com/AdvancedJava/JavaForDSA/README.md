# Java for DSA Toolkit

## Purpose
This directory bridges Core/Advanced Java concepts to Data Structures & Algorithms (DSA) problem solving.

## Complexity Quick Reference Cheat Sheet
| Data Structure / Operation | Time Complexity (Average) | Time Complexity (Worst) | Space Complexity |
|---|---|---|---|
| `ArrayList` access `get(i)` | O(1) | O(1) | O(N) |
| `ArrayList` insert/remove | O(N) | O(N) | O(1) |
| `HashMap` / `HashSet` search/put | O(1) | O(N) | O(N) |
| `TreeMap` / `TreeSet` search/put | O(log N) | O(log N) | O(N) |
| `PriorityQueue` offer/poll | O(log N) | O(log N) | O(N) |
| `Arrays.sort()` (Primitives) | O(N log N) | O(N log N) | O(N) |
| `Arrays.binarySearch()` | O(log N) | O(log N) | O(1) |
