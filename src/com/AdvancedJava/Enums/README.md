# Enums in Java

## Features
- **Type-Safety**: Replaces arbitrary `int` or `String` constants with compile-time type-checked enum instances.
- **Inheritance**: Enums extend `java.lang.Enum` implicitly (cannot extend another class, but CAN implement interfaces).
- **Singleton Pattern**: Declaring a single-element enum is the idiomatic way to implement a Singleton pattern in Java.
