# Wrapper Classes in Java

## Purpose
Wrapper classes convert primitives into object references, enabling primitive values to be stored in Generic collections (`List<Integer>`, `Map<String, Double>`) and passed into object-oriented frameworks.

## Primitive & Wrapper Mapping
| Primitive | Wrapper |
|---|---|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |
