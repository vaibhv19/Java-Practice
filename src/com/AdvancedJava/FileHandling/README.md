# File Handling in Java

## Stream Categories
- **Byte Streams (`InputStream` / `OutputStream`)**: Operates on raw 8-bit bytes (binary files, images, audio).
- **Character Streams (`Reader` / `Writer`)**: Operates on 16-bit Unicode characters (text files).

## Efficient I/O Classes
- `BufferedWriter` / `BufferedReader`: Buffers input/output characters to reduce disk read/write system calls.
