# Special Keywords: `this`, `super`, and `final`

## Summary Table
| Keyword | Variable Context | Method Context | Class Context |
|---|---|---|---|
| `this` | Refers to current instance variable | Calls current class method/constructor (`this()`) | N/A |
| `super` | Refers to parent class variable | Calls parent class method/constructor (`super()`) | N/A |
| `final` | Constant (cannot reassign) | Prevents method overriding | Prevents class inheritance |
