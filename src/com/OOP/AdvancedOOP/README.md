# Advanced OOP Concepts

## Topics
1. **Composition vs Inheritance**: Prefer HAS-A over IS-A relationships to achieve lower coupling and higher flexibility.
2. **Immutability Design Pattern**: Class made `final`, fields `private final`, defensive copies provided for mutable reference types.
3. **Inner & Nested Classes**:
   - Static Nested Class (`Outer.StaticNested`)
   - Member Inner Class (`outerInstance.new Inner()`)
   - Local Inner Class (Inside method)
   - Anonymous Inner Class (One-off inline instantiation)
