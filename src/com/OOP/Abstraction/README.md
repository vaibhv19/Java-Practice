# Data Abstraction in Java

## Definition
Abstraction hides internal complexity and exposes only essential feature contracts to the outside user.

## Abstract Classes
- Cannot be instantiated.
- Serves as a base class for specialized subclasses.
- Useful when subclasses share common state/code (concrete methods) alongside specialized abstract behaviors.
