# Encapsulation in Java

## Definition
Encapsulation is the mechanism of wrapping data (variables) and code acting on the data (methods) together as a single unit. In encapsulation, the variables of a class are hidden from other classes and accessed only through public methods.

## Benefits
1. **Data Hiding**: Internal representation is protected from illegal/unintended external modifications.
2. **Flexibility & Maintainability**: Internal implementation details can change without breaking client code.
3. **Validation Invariants**: Setter methods can enforce logic rules (e.g. `age > 0`, `balance >= 0`).
