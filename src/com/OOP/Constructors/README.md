# Constructors in Java

## Rules & Properties
1. **Name**: Constructor name must match class name exactly.
2. **Return Type**: Constructors have NO return type (not even `void`).
3. **Implicit Default Constructor**: If no constructor is written in a class, Java compiler automatically inserts a public no-arg default constructor.
4. **Constructor Chaining (`this()`)**: Used to call another constructor in the same class. Must be the first statement in the constructor.
