# Inheritance in Java

## Types of Inheritance Supported in Java
1. **Single Inheritance**: Subclass inherits from one Superclass.
2. **Multilevel Inheritance**: Class C extends Class B, which extends Class A.
3. **Hierarchical Inheritance**: Multiple subclasses extend a single Superclass.

> [!NOTE]
> **Multiple Class Inheritance is NOT allowed** in Java (e.g. `class C extends A, B`) to avoid the Diamond Problem ambiguity. Multiple inheritance is achieved strictly through **Interfaces**.
