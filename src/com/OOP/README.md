# Stage 2: Object-Oriented Programming (OOP)

Welcome to **Object-Oriented Programming in Java**. This stage covers OOP paradigms, principles, keywords, design concepts, and practice mini-projects.

## Package Naming Convention
All classes in this module follow the package naming convention:
`package com.OOP.<subfolder>;`

## Folder Overview
1. [`ClassesAndObjects/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/ClassesAndObjects/README.md) - Class blueprint definition, instance state (fields), behavior (methods), object instantiation via `new`.
2. [`Constructors/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Constructors/README.md) - Default constructor, parameterized constructor, overloading, constructor chaining via `this()`.
3. [`Keywords/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Keywords/README.md) - `this`, `super` keywords, `final` variables, methods, and classes.
4. [`AccessModifiers/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/AccessModifiers/README.md) - Visibility matrix: `private`, `default`, `protected`, `public`.
5. [`Encapsulation/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Encapsulation/README.md) - Data hiding, getters, setters, invariant state validation.
6. [`Inheritance/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Inheritance/README.md) - Single, multilevel, and hierarchical inheritance (`extends`).
7. [`Polymorphism/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Polymorphism/README.md) - Compile-time overloading vs Runtime overriding (dynamic method dispatch).
8. [`Abstraction/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Abstraction/README.md) - Abstract classes (`abstract`), concrete vs abstract methods.
9. [`Interfaces/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Interfaces/README.md) - Interfaces (`implements`), default methods, static interface methods, multiple interface inheritance.
10. [`AdvancedOOP/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/AdvancedOOP/README.md) - Composition vs Inheritance, immutable objects pattern, static/member/local/anonymous inner classes.
11. [`Projects/`](file:///D:/Work/Learning%20Engg/Java-Practice/src/com/OOP/Projects/README.md) - Educational practice projects: ATM, Library Management, Parking Lot.
